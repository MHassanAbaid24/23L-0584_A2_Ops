Is this image AI-generated?

Upload a picture and VisionGuard estimates whether it was made by a generative model or is a real (non-generated) image. The image is analysed in memory and is not stored.

Before you trust the verdict

  • The model was trained on fewer than 1,000 web images (art, portraits, animals, landscapes). It is right about 4 times out of 5 on held-out test images.
  • It is tuned to avoid calling a real image fake, so it misses some AI images, especially photorealistic portraits.
  • Paintings, heavy filters, screenshots and tiny thumbnails confuse it. Treat the result as a hint, not proof.
